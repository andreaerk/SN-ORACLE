# SN-ORACLE
## SuperNova Outcome Rates Across Comprehensive Large-scale single and binary stellar Evolution models

This population synthesis code is a post-processing tool that analyzes a large-scale input grid of detailed single and binary stellar evolution models to predict relative rates and features of the resulting supernove.

The current version is tested to work with Julia 1.12.7. Repository of old versions used in published work is available on Zenodo [10.5281/zenodo.22208968]
